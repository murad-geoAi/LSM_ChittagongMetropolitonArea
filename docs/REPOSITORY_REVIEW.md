- Includes explainability figures (SHAP summary + dependence plots).
- Map products are already present in publication-usable formats.

## Findings and Risks

### High Priority
1. PaperBanana figure generation is not reproducible without API credentials.
   - Evidence: local run fails due missing `GOOGLE_API_KEY` (and no `OPENAI_API_KEY` configured).
   - Impact: methodology figure cannot be regenerated by reviewers without setup instructions.
   - Action: add credential/setup section and keep command-ready prompt in repo (completed via `docs/PAPERBANANA_METHOD_FIGURE.md`).

2. Primary pipeline script is stored in `__pycache__/bayesian_lsm_pipeline.py` instead of `src/`.
   - Impact: confusing project structure and weak reproducibility optics for journal submission.
   - Action: move script to `src/bayesian_lsm_pipeline.py` and keep `__pycache__/` for compiled artifacts only.

### Medium Priority
3. Naming inconsistencies/typos in core folders and files.
   - Examples: `Metropoliton`, `Uncertinity`, `Suceptibility`.
   - Impact: reduces professionalism and may cause path mistakes in manuscript links.
   - Action: standardize names before final submission and update references.

4. `README.md` has visible encoding artifacts.
   - Impact: decreases readability and journal supplementary quality.
   - Action: save file in UTF-8 and normalize symbol characters.

5. No environment lockfile.
   - Impact: harder exact reproducibility across machines.
   - Action: add `environment.yml` or pinned `requirements-lock.txt`.

### Low Priority
6. Figure naming is partly inconsistent (`model_architecture.*` vs methodology naming).
   - Action: keep a single naming pattern (`figure_01_methodology`, `figure_02_study_area`, etc.).

## Publication Readiness Checklist (Suggested)
- [ ] Move/clean pipeline source paths (`src/` only).
- [ ] Standardize naming and spelling across directories/files.
- [ ] Normalize README encoding and refine language.
- [ ] Add environment lockfile and exact run command block.
